# SILICON LATTICE — Feedback de Beta 0.03

Canal público para errores de software, observaciones científicas y sugerencias.

**Aplicación:** https://silicon-lattice-public.irving2017cabs.workers.dev/

La aplicación se utiliza sin registro. Para enviar un Issue aquí necesitas iniciar sesión en GitHub. Los reportes y comentarios son públicos.

Usa **Issues → New issue** y elige una plantilla. Indica el módulo, los pasos, el resultado esperado y el observado. Para un posible error científico incluye ecuación, hipótesis, unidades y una fuente verificable cuando esté disponible; un reporte no se acepta automáticamente como corrección científica.

No adjuntes nombres de estudiantes, calificaciones, exportaciones completas de IndexedDB, correos personales, tokens, cookies, contraseñas ni documentos privados. Revisa y oculta datos personales en capturas. No publiques vulnerabilidades con secretos o pasos que pongan datos privados en riesgo; comunica inicialmente sólo una descripción general sin detalles sensibles.

Este repositorio contiene únicamente documentación y plantillas de Issues. No contiene el fuente de la aplicación, artefactos de auditoría ni un mecanismo de despliegue. Abrir un Issue no modifica la versión oficial ni otorga acceso administrativo. Las correcciones requieren revisión y una nueva publicación autorizada.

Moderación: mantener los reportes centrados en el problema, cerrar duplicados y spam; el propietario puede usar los controles de bloqueo, denuncia y límites temporales de interacción de GitHub. No se han activado restricciones que impidan a nuevos testers reportar problemas.

Beta experimental: la verificación física de Safari/iPhone sigue pendiente. El progreso se guarda localmente en el navegador de cada visitante; este canal no recibe esos datos automáticamente.
